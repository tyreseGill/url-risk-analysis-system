# Documentation

This directory contains supporting documentation for the URL Risk Analysis System.

## Contents

### Architecture

- [architecture.md](architecture.md)

System design documentation, including:

- Network topology
- Risk analysis hierarchy
- Multi-stage evaluation pipeline
- Analysis methods and data sources

### Command Line Interface

- [cli.md](cli.md)

Documentation for the command-line interface, including:

- Available commands
- Command-line arguments
- Usage examples
- Common workflows

### Dataset Overview

- [dataset_overview.ipynb](dataset_overview.ipynb)

Read-only exploratory data analysis (EDA) notebook documenting:

- Dataset characteristics
- Target class distribution
- Feature groups
- Feature selection decisions

> [!NOTE]
> The notebook serves as project documentation and is not required to run the application.

## Purpose

The documentation in this directory is intended to help users, contributors, and reviewers understand the architecture, data pipeline, command-line functionality, and design decisions underlying the URL Risk Analysis System.
